TELEMETRY INQUIRIES

Frequently Asked Questions

Everything you need to know regarding safety, platform coverage, and architecture.

How does FaizIt work without any servers? +
FaizIt embeds the lightweight youtubedl-android library, which packages modern yt-dlp and C++ FFmpeg directly inside the Android APK. When you share a URL, the extractor resolves the stream manifests right on your phone via residential bandwidth, ensuring zero hosting costs and zero server downtime.
Is FaizIt safe to install on Android? +
100% safe. FaizIt contains zero advertising SDKs, zero analytics trackers, and zero remote payload downloaders. The entire codebase is completely open source under the MIT license, and builds are transparently assembled by GitHub Actions CI/CD.
Where do my downloaded videos and MP3 files go? +
Files are saved to your public phone storage at /Download/FaizIt/. Upon download completion, FaizIt calls the Android MediaScannerConnection API so your files instantly show up in Google Photos, Gallery, Apple Music, and VLC.
What happens if Instagram or YouTube changes its layout? +
Inside the FaizIt main dashboard, tap the refresh icon in the top app bar. This triggers YoutubeDL.updateYoutubeDL(), pulling the newest platform extraction rules over-the-air in seconds without requiring an APK update.
Can I extract audio only as high-bitrate MP3? +
Yes. FaizIt bundles the full FFmpeg executable. When you choose the "Audio Only" preset, FFmpeg extracts the high-quality audio stream and converts it directly into a clean 320kbps MP3 file.
